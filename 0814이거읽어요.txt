0814 읽어주세요 — 스프레드시트 전면 개편 완료 보고

■ 무엇이 바뀌었나 (코드는 전부 GitHub main에 푸시됨)

1. 스프레드시트 2개(① 사이트인증 / ② 통합관리자) → 1개로 통합.
   - 기준 파일은 ① (웹앱·북마클릿이 붙어 있는 파일)이라서 웹앱 재배포가 필요 없습니다.
2. 대시보드 전면 교체:
   - 유폴리오 마스터 항목 206개(행) × 학생 출석번호 1번~끝(열) 매트릭스.
   - 각 항목의 평균 열 포함. 아직 유폴 안 보낸 학생도 열은 보이고 머리글이 회색.
   - 항목 행을 클릭하면 우측 상단 막대그래프에 그 항목의 값 분포가 뜸.
3. 비교결과는 딱 이 열만: 출석번호 / 학번 / 이름 / 과 / 현황표시명 / 측정값 / 현황값 /
   U-FOLIO 값 / 사인 대기 횟수 / 최신 유폴 인증(그 학생의 마지막 전송 시각).
   - 유폴 미인증이면 U-FOLIO 값에 '미인증'(빨강). 값 다르면 노랑, 같으면 초록.
4. 현황시트연결은 그대로 유지.
5. 새 시트 '측정값설정': 항목마다 승인수/환자수/점수 중 뭘로 비교·집계할지 드롭다운으로 선택.
   바꾼 뒤 메뉴에서 '지금 전체 동기화'를 실행하면 비교결과·대시보드에 모두 반영됩니다.
6. 나머지 시트(RAW, 항목매핑, 연결진단, 동기화로그 등 13개)는 전부 숨김.
   보이는 탭은 대시보드 / 비교결과 / 현황시트연결 / 측정값설정 4개뿐.
   숨긴 시트는 좌측 하단 시트 목록(☰)에서 언제든 다시 열 수 있어요.

■ 다음 컴퓨터에서 실제로 해야 할 일 (관리자 구글 계정, 약 5분)

1. ① 사이트인증 Google Sheets 열기 → 확장 프로그램 → Apps Script.
2. 저장소의 apps-script/ 폴더 6개 파일을 전부 최신 내용으로 교체:
   Code.gs / CaseSheetCore.gs / CaseSheetDefaults.gs / CaseSheetSync.gs /
   CaseSheetDashboard.gs(★새 파일, 새로 만들어야 함) / SystemSetup.gs
3. 시트로 돌아와 새로고침 → 메뉴 [유폴리오 통합관리 → ② 관리자 파일 가져오기 (1회)] 실행.
   → ②에 입력해둔 현황시트 URL·매핑 검토상태·동기화 이력이 ①로 복사되고,
     화면 구성 적용 + 전체 동기화까지 자동으로 됩니다.
4. 대시보드·비교결과가 채워졌는지 확인. 이후 ② 파일은 안 쓰니 보관/휴지통 처리.
5. 새벽 3시 자동 동기화 트리거는 그대로 살아 있습니다(refreshIntegratedData 그대로).

■ 알아두면 좋은 것

- 웹앱(doPost)·북마클릿·config.js는 건드리지 않았습니다. 재배포 불필요.
- 대시보드 클릭 그래프는 onSelectionChange 단순 트리거라 별도 설정 없이 동작하는데,
  스마트폰 앱에서는 클릭 이벤트가 잘 안 옵니다. PC 브라우저 기준으로 쓰세요.
- 측정값설정이 '진짜 기준'입니다. 항목매핑에 적힌 측정값보다 우선하고,
  이관 시 ②의 항목매핑에서 쓰던 측정값이 기본값으로 채워집니다.
- 비교결과에서 상태 글자 열은 없앴고 색으로만 구분합니다(빨강 미인증/노랑 다름/초록 일치).
  검토필요·보류 매핑은 비교결과에 안 올라가고 숨긴 '미매핑항목'에만 남습니다.
- 화면이 꼬이면 언제든 메뉴 [화면 구성 새로 적용] — 데이터는 안 지워집니다.
- 테스트 61개 전부 통과(npm.cmd test). 빌더도 단일 파일(01_유폴리오_통합.xlsx) 기준으로 고쳤습니다.
- 이 저장소(ufolio) main에 푸시했습니다. 달신 프로젝트 브랜치(main 로컬)는 건드리지 않았어요.
  다음 컴퓨터에서 이 폴더를 clone/checkout 할 때는 codex/ufolio-standalone = origin/main 입니다.
