# Apps Script 설치

Apps Script는 ① 사이트 인증 Google Sheets에 바인딩합니다. ② 통합 관리자 파일은 스크립트가 생성하고 ID를 ① `설정` 탭에 저장합니다.

## 파일 붙여넣기

① 파일에서 `확장 프로그램 → Apps Script`를 열고 아래 스크립트 파일을 각각 만듭니다. 각 저장소 파일의 전체 내용을 같은 이름의 Apps Script 파일에 붙여넣습니다.

1. `Code.gs`
2. `CaseSheetCore.gs`
3. `CaseSheetDefaults.gs`
4. `CaseSheetSync.gs`
5. `SystemSetup.gs`

① 파일을 반드시 `파일 → Google 스프레드시트로 저장`으로 변환한 다음, 함수 목록에서 `createIntegrationAdminWorkbook`을 한 번 실행하고 Google 권한을 승인합니다. ① `설정`에 `ADMIN_SPREADSHEET_ID`와 URL이 생기며, Google Drive에 `② 유폴리오 통합관리자`가 생성됩니다. `.xlsx` 편집 모드에서는 `setFrozenRows` 권한 오류가 발생할 수 있습니다.

## 메뉴 순서

① 파일을 새로고침하면 `유폴리오 통합관리` 메뉴가 나타납니다.

1. `현황시트 연결 검사`
2. `지금 전체 동기화`
3. `매일 새벽 3시 동기화 켜기`

기본 연결이나 매핑 행을 실수로 삭제했을 때는 `기본 연결·매핑 누락분 추가`를 실행합니다. 기존 URL과 검토상태는 덮어쓰지 않고 누락 키만 추가합니다.

2026-08-08 재검토 매핑을 기존 ② 파일에 적용할 때는 `검토 완료 매핑 교정 적용`을 한 번 실행합니다. 이 함수는 원본 URL과 사용자 추가 매핑을 보존하고, 관리되는 기본 매핑만 최신 정의로 교체한 뒤 전체 동기화를 실행합니다.

## 원본 권한

Apps Script를 실행하는 관리자 Google 계정을 각 케이스장 Google Sheets에 `뷰어`로 공유합니다. 편집 권한은 필요하지 않습니다. 연결 URL은 ② `현황시트연결`의 노란 E열에만 입력하며 저장소 코드에는 넣지 않습니다.

동기화는 설정된 출석번호·이름 열과 매핑식이 참조하는 열만 읽습니다. 원본 행 전체나 환자 상세를 중앙 파일에 복사하지 않습니다.

## 웹 앱 배포

1. `배포 → 새 배포`
2. 유형 `웹 앱`
3. 실행 사용자 `나`
4. 액세스 권한 `모든 사용자`
5. 배포 후 `/exec` URL을 `config.js`의 `WEB_APP_URL`에 입력

`Code.gs`를 바꾼 뒤에는 기존 배포를 새 버전으로 갱신해야 합니다. 새 URL이 발급되면 `config.js`와 Vercel 배포도 갱신합니다.

`doPost(e)`는 ① 파일의 명단·마스터를 검증하고 RAW·전송기록만 추가합니다. 외부 현황시트 읽기는 수동 메뉴 또는 새벽 3시 트리거에서만 실행됩니다.
