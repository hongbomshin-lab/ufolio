# Apps Script 설치

시스템은 이제 **스프레드시트 한 개**로 동작합니다. 학생 제출 수신(RAW)과 현황시트 비교·대시보드가 모두 같은 파일에 있습니다.

## 파일 붙여넣기

스프레드시트에서 `확장 프로그램 → Apps Script`를 열고 아래 6개 파일을 각각 만들어 같은 이름의 저장소 파일 전체 내용을 붙여넣습니다.

1. `Code.gs`
2. `CaseSheetCore.gs`
3. `CaseSheetDefaults.gs`
4. `CaseSheetSync.gs`
5. `CaseSheetDashboard.gs`
6. `SystemSetup.gs`

xlsx로 업로드한 파일이라면 반드시 `파일 → Google 스프레드시트로 저장`으로 먼저 변환합니다. `.xlsx` 편집 모드에서는 권한 오류가 발생합니다.

## 메뉴

파일을 새로고침하면 `유폴리오 통합관리` 메뉴가 나타납니다.

- `현황시트 연결 검사` / `지금 전체 동기화` — 평소 운영
- `매일 새벽 3시 동기화 켜기` / `자동 동기화 끄기`
- `화면 구성 새로 적용` — 시트 순서·숨김·대시보드·서식을 다시 그림 (데이터는 보존)
- `기본 연결·매핑 누락분 추가` — 기본값을 실수로 지웠을 때
- `② 관리자 파일 가져오기 (1회)` — 예전 2-파일 구조에서 넘어올 때 한 번만 실행

## 예전 2-파일 구조에서 넘어오기 (1회)

① 사이트 인증 파일에서 위 6개 스크립트를 최신으로 교체한 뒤 `② 관리자 파일 가져오기 (1회)`를 실행하면:

1. ② 파일의 `현황시트연결`(URL 포함)·`항목매핑`·`현황최신`·`동기화로그`를 ①로 복사하고
2. 화면 구성을 적용하고 전체 동기화를 실행합니다.

이후 ② 파일은 사용하지 않으므로 보관하거나 휴지통으로 옮깁니다.

## 보이는 시트 / 숨긴 시트

- **보임:** `대시보드`, `비교결과`, `현황시트연결`, `측정값설정`
- **숨김(시스템 운영용):** `항목매핑`, `미매핑항목`, `연결진단`, `동기화로그`, `현황최신`, `유폴리오최신`, `마스터항목`, `학생명단`, `RAW`, `전송기록`, `설정`, `차트데이터`, `사용안내`
  - 좌측 하단 시트 목록(☰)에서 언제든 다시 열 수 있습니다.

`측정값설정`에서 항목별로 승인수/환자수/점수 중 무엇으로 비교·집계할지 고르고, `지금 전체 동기화`를 실행하면 비교결과와 대시보드에 반영됩니다.

`대시보드`는 유폴리오 최신 제출 기준의 항목×학생 매트릭스입니다. 항목 행을 클릭하면 우측 상단 그래프에 그 항목의 값 분포가 표시됩니다. (`onSelectionChange` 단순 트리거)

## 원본 권한

Apps Script를 실행하는 관리자 Google 계정을 각 케이스장 Google Sheets에 `뷰어`로 공유합니다. 편집 권한은 필요하지 않습니다. 연결 URL은 `현황시트연결`의 노란 E열에만 입력하며 저장소 코드에는 넣지 않습니다.

동기화는 설정된 출석번호·이름 열과 매핑식이 참조하는 열만 읽습니다. 원본 행 전체나 환자 상세를 중앙 파일에 복사하지 않습니다.

## 웹 앱 배포

1. `배포 → 새 배포`
2. 유형 `웹 앱`
3. 실행 사용자 `나`
4. 액세스 권한 `모든 사용자`
5. 배포 후 `/exec` URL을 `config.js`의 `WEB_APP_URL`에 입력

`Code.gs`를 바꾼 뒤에는 기존 배포를 새 버전으로 갱신해야 합니다. 새 URL이 발급되면 `config.js`와 Vercel 배포도 갱신합니다. **이번 개편은 `Code.gs`를 바꾸지 않았으므로 웹 앱 재배포가 필요 없습니다.**

`doPost(e)`는 명단·마스터를 검증하고 RAW·전송기록만 추가합니다. 외부 현황시트 읽기는 수동 메뉴 또는 새벽 3시 트리거에서만 실행됩니다.
