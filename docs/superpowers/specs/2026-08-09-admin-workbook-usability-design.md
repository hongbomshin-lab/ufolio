# 통합관리자 워크북 사용성 개선 설계

## 목표

관리자가 일상적으로 `대시보드`와 `비교결과`만 보아도 현재 상태와 후속 조치를 이해할 수 있게 한다. 오류가 있을 때는 `연결진단`과 `동기화로그`, 원본 구조가 바뀔 때만 `현황시트연결`과 `항목매핑`을 사용하도록 시각적 우선순위를 만든다.

기존 케이스장 원본, 관리자 파일의 원본 URL, 사용자 추가 매핑, 집계 데이터는 수정하거나 삭제하지 않는다.

## 확정된 매핑 규칙

- 보철 기공 X열은 가철성·고정성·임플란트 Laboratory case evaluation 승인 건수 합계다.
- 보철 기공 Y열은 같은 세 항목의 점수 합계다.
- Biopsy report F열과 I&D report K열의 값은 레포트 사인 완료를 뜻하며 각각 Total Case 1건으로 계산한다.
- I&D 2nd와 3rd visit은 U-FOLIO follow-up 승인 1건씩, 합계 2건으로 계산한다.
- 위 규칙의 비고에서 `임시`, `확인 필요` 표현을 제거한다.

## 관리자 시트 사용 흐름

시트는 다음 순서로 배치한다.

1. `대시보드`: 매일 첫 화면
2. `비교결과`: 학생별 차이 확인
3. `연결진단`: 원본 오류 확인
4. `동기화로그`: 최근 실행 결과 확인
5. `미매핑항목`: 새 항목이나 보류 매핑 확인
6. `현황시트연결`: 원본 URL·탭 구조 변경 시 사용
7. `항목매핑`: 매핑 규칙 변경 시 사용
8. `현황최신`: 기술 확인용
9. `유폴리오최신`: 기술 확인용
10. `마스터항목`: 기술 확인용
11. `사용안내`: 상세 운영 설명

워크북이 열리거나 사용성 업데이트 함수가 실행된 뒤에는 `대시보드`를 활성 시트로 둔다.

## 탭 역할 색상

- 일상 확인: 진한 파랑 (`대시보드`, `비교결과`)
- 오류·주의 확인: 빨강 또는 주황 (`연결진단`, `동기화로그`, `미매핑항목`)
- 관리자 설정: 노랑 (`현황시트연결`, `항목매핑`)
- 기술 자료: 회색 (`현황최신`, `유폴리오최신`, `마스터항목`)
- 설명: 연한 파랑 (`사용안내`)

색상은 역할 구분에만 사용하며, 상태 의미를 나타내는 기존 조건부 서식과 충돌하지 않게 한다.

## 대시보드

대시보드는 세 구역으로 구성한다.

### 오늘의 확인 항목

- 확인 필요 합계
- 반영대기
- 현황누락의심
- 유폴리오미인증
- U-FOLIO측정값없음
- 매핑대기

모든 값은 `비교결과` 수식으로 계산한다. 확인 필요 합계는 위 다섯 상태의 합이다.

### 운영 상태

- 마지막 동기화 시각
- 정상 연결 수
- 오류·노후 연결 수
- 전체 비교 건수
- 일치 건수
- 일치율

마지막 동기화가 없으면 `아직 동기화 전`으로 표시한다. 일치율은 비교 건수가 없을 때 0%로 표시한다.

### 바로 보는 순서

일상·오류·설정·기술 시트의 용도를 짧게 설명한다. 별도 차트는 추가하지 않는다. 현재 운영에서는 차트보다 상태별 건수와 다음 행동이 더 직접적이다.

## 표 시트 사용성

- 모든 운영 표는 첫 행을 고정하고 필터를 제공한다.
- `비교결과`는 출석번호·학번·이름 3개 열을 고정한다.
- `비교결과`는 J열 상태에 따라 A:M 전체 행에 연한 상태색을 적용한다.
- `현황시트연결`은 소스키·활성·과·표시명 4개 열을 고정한다.
- `항목매핑`은 매핑키·활성·검토상태·소스키 4개 열을 고정한다.
- `연결진단`, `동기화로그`, `미매핑항목`은 필터와 읽기 쉬운 열 너비를 유지한다.
- 동기화 시 내용만 교체하고 서식·필터·고정 열은 유지한다.

## 기존 Google Sheets 업데이트

`관리자 화면·서식 업데이트` 메뉴를 추가한다. 이 함수는 다음만 수행한다.

- 대시보드와 사용안내 재작성
- 탭 순서와 탭 색상 적용
- 필터, 고정 행·열, 열 너비, 조건부 서식 적용
- 대시보드를 활성 시트로 선택

원본 URL, 연결 상태 데이터, 매핑 행, 비교 결과, 동기화로그는 변경하지 않는다. `검토 완료 매핑 교정 적용`도 같은 사용성 업데이트를 자동으로 실행한다.

## 생성 XLSX

새로 생성하는 ② 워크북도 같은 시트 순서, 대시보드 구조, 색상 역할, 필터, 고정 창, 조건부 서식을 갖는다. 기술적 제약으로 탭 색상이 XLSX 렌더러에서 지원되지 않으면 셀 안의 역할 안내와 시트 순서를 우선한다.

## 검증

- 세 확정 규칙의 매핑식·측정값·비고를 테스트한다.
- Apps Script에 사용성 업데이트 메뉴와 함수가 있는지 테스트한다.
- 생성기에서 대시보드 수식이 참조 시트 생성 뒤 작성되는지 테스트한다.
- 생성 XLSX가 학생 93명, 마스터 206개, 소스 11개, 매핑 63개를 유지하는지 확인한다.
- 전 시트 수식 오류를 검사하고 모든 시트를 렌더링한다.
- 대시보드, 비교결과, 연결진단, 현황시트연결을 직접 시각 검토한다.
