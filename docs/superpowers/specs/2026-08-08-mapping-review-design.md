# U-FOLIO 현황시트 매핑 재검토 설계

## 목표

현재 통합 관리자 파일의 `항목매핑`을 실제 과별 현황시트 구조와 사용자가 확인한 운영 규칙에 맞게 교정한다. 한 과의 규칙을 다른 과에 일반화하지 않으며, 확인되지 않은 항목은 `검토필요` 또는 비활성 상태로 남긴다.

## 확정 원칙

- 측정값은 항목별로 `점수`, `승인수`, `환자수` 중 사용자가 명시한 값을 사용한다.
- 치주 Flap/Implant, 보철 가철/고정/임플란트/임수, 구강내과 물리치료의 예정값은 앞으로 할 예정이거나 배정만 받은 값도 포함한다.
- 소아 차팅은 점수가 아니라 차팅 건수와 U-FOLIO 승인 건수를 비교한다.
- 구강내과 차팅은 현황시트 C열을 사용한다. 사용자가 환자수가 중요하다고 명시한 구강내과 항목은 환자수로 비교하되, 원본 자체가 점수인 물리치료 I+J는 확인 전까지 점수 비교를 유지한다.
- 외과 발치, 임플란트, minor 항목 중 사용자가 명시한 항목은 승인 건수로 비교한다.
- 병리는 독립된 `O` 표기가 있는 값만 1건으로 센다. `X`, 예정, 날짜만 있는 값은 세지 않는다.

## 매핑 변경

### 구강악안면외과

- C 말리컨 → `수술실-Malignant tumor and/or reconstruction surgery(free flap)`
- D 양악 → `수술실-Maxillofacial deformity and orthognathic surgery`
- E cyst → `수술실-Cyst and benign tumor surgery`
- F 발치 → `수술실-Surgical extraction`
- G 기타 → `수술실-기타`
- H Extraction A, R Minor recall, S 신환 차팅은 승인수 비교로 변경한다.
- K Implant A는 2개 이하 A와 3개 이상 A 승인수를 합산한다.
- 별도 임플란트 현황 C열은 두 O 항목 합산 후보로 두되, 현재 학년 자료인지 확인될 때까지 연결과 매핑을 비활성/검토 상태로 둔다.
- Biopsy 단계는 D:E, I&D 단계는 H:J만 세어 report 열을 제외한다.

### 보철과

- G/K/N 누적 → 각각 가철성/고정성/Implant Total case 승인수
- S 차팅 → `22. Charting` 승인수
- T 진토 → `Charting and Treatment planning evaluation` 승인수
- U 단타 → `01. Student evaluation` 점수
- V 교픽 → `02. observation (교수님)` 점수
- Q 임수 누적 → `03. Implant assist` 승인수
- 기존 U+V 기공 매핑은 비활성화한다. X/Y 기공은 대상 구분이 확인될 때까지 검토필요로 남긴다.

### 구강내과·치주·소치·병리

- 구강내과 차팅은 C열을 사용하고, 물리치료를 제외한 현황 건수 항목은 환자수 비교로 통일한다.
- 치주와 소치의 사용자가 확인한 건수 규칙은 유지한다.
- 병리에는 `HAS_STATUS_O` 제한 집계식을 추가한다.

## 기존 관리자 파일 마이그레이션

`applyReviewedMappingCorrections`를 실행하면 다음을 수행한다.

1. 현재 관리자 파일을 찾아 `항목매핑`의 기본 매핑키를 최신 정의로 교체한다.
2. 사용자 추가 매핑은 보존한다.
3. `현황시트연결`의 URL과 운영 상태를 보존하면서 PROS 종료행을 96, OMS 종료행을 94로 고친다.
4. 의미가 확인되지 않은 IMPLANT 연결은 비활성화한다.
5. 서식 적용 후 전체 동기화를 실행한다.

## 안전장치

- 원본 Google Sheets는 읽기 전용이며 수정하지 않는다.
- 환자명·환자번호는 중앙 파일에 저장하지 않는다.
- Resin, Endo, Biopsy/I&D report, 보철 X/Y 기공은 임의 확정하지 않는다.
- 새 기본값과 기존 관리자 파일 업데이트가 같은 매핑 정의를 사용하도록 하여 재생성 시 회귀를 막는다.

## 검증

- 제한 집계식의 O 판정 테스트
- 모든 승인 매핑의 U-FOLIO 마스터 대상 존재 검증
- 항목별 측정값·열·대상·검토상태 회귀 테스트
- 기존 URL/사용자 추가행 보존 마이그레이션 테스트
- 전체 Node 테스트와 스프레드시트 패키지 생성·검증
