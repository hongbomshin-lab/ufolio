# 지정 항목 점수 미수집 적용 가이드

이 변경은 아래 8개 항목에서 `점수`와 `점수 원문`을 북마클릿 전송 데이터에서 제외합니다. 승인수·승인대기수·환자수와 항목 식별 정보는 이전처럼 전송합니다.

- 치주과 / 증례별 임상참여 / `Flap Assist`
- 치주과 / 증례별 임상참여 / `Implant Assist`
- 구강악안면외과 / 증례별 임상참여 / `수술실-Malignant tumor and/or reconstruction surgery(free flap)`
- 구강악안면외과 / 증례별 임상참여 / `수술실-Maxillofacial deformity and orthognathic surgery`
- 구강악안면외과 / 증례별 임상참여 / `수술실-Cyst and benign tumor surgery`
- 구강악안면외과 / 증례별 임상참여 / `수술실-Surgical extraction`
- 구강악안면외과 / 증례별 임상참여 / `수술실-기타`
- 영상치의학과 / 나절별 임상참여 / `판독 토론 및 평가`

## 1. 스프레드시트 Apps Script에서 할 일

1. 통합 스프레드시트에서 `확장 프로그램 → Apps Script`를 엽니다.
2. 저장소의 최신 내용으로 다음 파일 5개를 교체하고 저장합니다.
   - `Code.gs`
   - `CaseSheetCore.gs`
   - `CaseSheetSync.gs`
   - `CaseSheetDashboard.gs`
   - `SystemSetup.gs`
3. `배포 → 배포 관리`에서 현재 웹 앱 배포의 편집 버튼을 누릅니다.
4. 버전을 `새 버전`으로 선택하고 배포합니다. 기존 배포를 갱신하면 `/exec` URL은 그대로 유지됩니다.
5. 스프레드시트를 새로고침합니다.
6. 메뉴 `유폴리오 통합관리 → 점수 안받음 정책 기존 RAW 적용`을 한 번 실행합니다. 과거에 저장된 대상 점수는 삭제되고 `안받음`으로 바뀝니다.
7. 메뉴 `유폴리오 통합관리 → 지금 전체 동기화`를 실행합니다.

Apps Script는 새 북마클릿뿐 아니라 구버전 북마클릿이 대상 점수를 보내는 경우에도 서버에서 해당 점수를 폐기합니다.

## 2. 유폴 인증 북마클릿 사이트에서 할 일

1. `bookmarklet.js`와 `index.html`이 포함된 최신 커밋을 정적 사이트에 배포합니다.
2. 배포 사이트를 강력 새로고침한 뒤 설치 버튼을 다시 즐겨찾기 바로 끌어 놓습니다.
3. 기존 즐겨찾기 북마클릿은 자동 갱신되지 않으므로 학생들에게 기존 북마클릿을 삭제하고 새로 설치하도록 안내합니다.
4. 테스트 계정으로 실행해 전체 항목 보기에서 대상 8개 항목의 점수가 `안받음`으로 보이는지 확인합니다.
5. 브라우저 개발자 도구의 Network에서 Apps Script `/exec` 요청 본문을 확인해 대상 항목에 `score`, `scoreRaw` 속성이 없는지 확인합니다.
