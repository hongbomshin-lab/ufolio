# 케이스장 추가 확인 질문

2026-08-09까지 받은 답변은 모두 반영했습니다. 아래 세 가지는 현재 가장 그럴듯한 방식으로 먼저 적용했지만, 정확도를 위해 담당 케이스장의 확인이 필요합니다.

```text
1. [보철과 기공 X열·Y열]

현황시트의 X열 ‘기공(3)’과 Y열 ‘기공 점수(15)’는
가철성·고정성·임플란트 기공을 전부 합친 총계인가요?

A. 예. X는 세 종류의 승인 건수 합계이고, Y는 세 종류의 점수 합계입니다.
B. 아니요. 특정 종류의 기공만 뜻합니다. 해당 종류: __________
C. 세 종류를 따로 구분할 수 있습니다. 구분된 값이 있는 열/탭: __________


2. [외과 Biopsy / I&D report 입력 시점]

‘3-2 biopsy / I and D’ 시트의 Biopsy report(F열), I&D report(K열)는
레포트 사인까지 끝나 Total Case를 승인받을 수 있을 때만 입력하나요?

A. 예. F/K에 값이 있으면 레포트 사인 완료로 보면 됩니다.
B. 아니요. 사인 전에도 값을 입력합니다. 사인 완료를 구분하는 방법: __________


3. [외과 I&D 2nd·3rd follow-up 승인 수]

I&D 환자 한 명이 2nd와 3rd visit을 모두 마치면,
U-FOLIO ‘follow-up(I&D) 2nd or 3rd visit’ 승인 건수는 총 몇 건이 되나요?

A. 2건입니다. 2nd와 3rd를 각각 한 건씩 승인받습니다.
B. 1건입니다. 2nd와 3rd를 묶어서 한 번만 승인받습니다.
C. 다른 방식입니다: __________
```

현재 임시 적용:

- 보철 기공 X/Y는 가철성·고정성·임플란트 세 항목의 합계와 비교합니다.
- Biopsy/I&D report 셀은 값이 있으면 Total Case 1건 완료로 계산합니다.
- I&D의 1st·2nd·3rd 날짜는 각각 1건으로 계산하고, U-FOLIO의 I&D + follow-up 합계와 비교합니다.
